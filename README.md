# Lexical Analyzer

## Description
A Lexical Analyzer developed using C programming.
It is the first phase of a compiler that reads source code
and identifies meaningful tokens.

## Features
- Token Identification and Classification
- Keyword Recognition
- Identifier Recognition
- Operator and Symbol Recognition
- Line and Column Tracking
- Lexical Error Detection
- Token Frequency Summary

## Technologies Used
- C Programming (C11)
- GCC Compiler
- Data Structures
- File Handling
- GNU Make

## Compilation
make

## Execution
./lexer sample.c
